## 🧩 Como estou estudando

A ideia não é apenas encontrar uma solução que funcione.

Para cada problema, procuro entender:

1. Qual é o problema?
2. Qual estratégia posso utilizar?
3. Qual padrão de algoritmo aparece?
4. Qual é a complexidade de tempo?
5. Qual é a complexidade de espaço?
6. Existe uma solução mais eficiente?
7. O que posso aprender com esse problema?
